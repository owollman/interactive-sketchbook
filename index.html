Reflection

The specific idea from the reading that I used was the idea of usage priority and placement. Since the three pages I am linking to are the main pages of my website, that I expect people to click on the most, I put the navigation at the top of the pages so the user can clearly see and navigate to each one.

While linking the pages together I learned how to correctly change the punctuation on the lines of code between each different page. In order to link the child pages to the parent page you have to start the link differently since you are navigating out of the current file the page is on and are going to another folder within the parent.
