What does this mean?
“width=device-width”– width of page is the same as width of viewport
MY WEBSITE ADAPTS TO THE WIDTH OF THE DEVICE
ex: if the viewport is 325px wide, the page will display as 325px wide
“initial-scale=1.0” – page should not zoom in/out when first loaded.

place the gifs side-by-side to compare the difference between fixed/fluid/responsive

fixed – this is us now

fixed layouts rely on a static container with a fixed pixel width. resizing browser has no impact

fluid – we kinda know this

fluid layouts use relative units and the layout increases/decreases with the browser window. layout breaks at small scale

responsive – GOALS

responsive web design is about using HTML and CSS to automatically resize, hide, shrink or enlarge a website to make it look good across all devices.
