Reflection

Before starting this assignment I was really intimidated by the thought of using what I know about CSS to create a page that mimics the included image. I forgot a lot of the tags for certain things. I knew that there was an option to put padding around the box that the text sits in but it took me longer than I'd like to admit to come up with the correct way to write it in CSS. I also forgot how to size an image to the text until I went back through my other pages to figure out how I applied that on other pages with images. In my other pages I had never really used classes as much as I have here. I feel like it is a good tool for organizing features so you can mass edit one group but I'm not sure I'm using them in the most effective way.

One thing I had the most trouble with was changing the color of the text that had links attached to it. I tried putting the color variations for the nav tag and the h1-h3 tags but the only one that worked was within the a tag. But obviously that is going to impact everything within that group. I mainly just don't understand why changing the colors did nothing within the other tags. I even switched the order of them around to see if that would change anything but it did not.
